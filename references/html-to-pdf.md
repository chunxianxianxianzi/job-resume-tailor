# PDF 简历生成与检查（跨 Agent）

简历最终交付格式统一为 PDF。HTML、Markdown 或文档源文件可作为中间材料，不代表最终 PDF 已交付。本说明不绑定某个 Agent 的工具名，也不假定所有环境都有浏览器或转换工具。

## 先检查当前环境

- 查看已有的 PDF 生成能力、可用中文字体，以及打开 PDF 或将页面渲染为图片的能力。
- 优先使用环境已提供的文档或 PDF 工具。需要安装依赖时，先遵循当前环境的权限和安装规则，不默认修改系统。
- 选定一种实际可执行的方法，无须安装或尝试全部工具。缺少生成能力时说明具体缺项，保留内容草稿，并说明完成 PDF 所需的下一步。

## 按可用工具选择生成方式

### 有可操作的浏览器或浏览器 PDF 导出能力

将 HTML 中间材料载入浏览器，使用其 PDF 导出能力，或在可操作的打印界面选择「另存为 PDF」。采用 A4，确认边距，关闭网页地址和打印日期等页眉页脚，并检查实际分页。仅有联网搜索功能不代表 Agent 能操作浏览器打印。

### 已有 WeasyPrint 运行环境

先确认 WeasyPrint 的运行依赖和中文字体可用，再执行，例如：

```bash
python -c "from weasyprint import HTML; HTML('简历.html').write_pdf('简历.pdf')"
```

只有 Python 或仅执行 `pip install weasyprint` 不代表环境已配置完成；WeasyPrint 还涉及 Pango 等系统库。按当前系统核对 [WeasyPrint 官方安装说明](https://doc.courtbouillon.org/weasyprint/stable/first_steps.html)。

### 已有 Pandoc 与可用 PDF 引擎

明确选择实际可用的 PDF 引擎，不只执行 `pandoc 简历.html -o 简历.pdf` 并假定成功。例如，环境已有 WeasyPrint 时可使用：

```bash
pandoc 简历.html -o 简历.pdf --pdf-engine=weasyprint
```

Pandoc 默认经 LaTeX 生成 PDF；引擎选择与样式处理参见 [Pandoc 官方说明](https://pandoc.org/MANUAL.html)。转换后的页面仍须实际检查，不能假定 HTML 样式已完整保留。

### 已有其他 PDF 生成或导出工具

可使用环境已有的 PDF 库、Word、LibreOffice 等工具生成或导出 PDF；中间文档无须作为交付物提供。确认所选工具能正确处理中文、分页与字体，再生成文件。

## 检查最终 PDF

1. 确认文件是可打开的实际 PDF，不只是把其他文件的后缀改成 `.pdf`。
2. 打开或渲染全部页面，检查中文是否正常、文字是否清晰，有无截断、重叠、异常空白页或标题与正文跨页分离。
3. 核对姓名、联系方式、教育时间、经历、技能等内容与用户已提供的信息一致。教育日期保留用户提供的精度，不自动补月份。
4. 检查文本能否选中或提取；在工具支持时优先生成有文本层的 PDF，避免整页图片式简历。
5. 多岗位核对文件名和内容一一对应。修复问题后重新生成并检查，交付时说明检查结果和待补充信息。

无法生成 PDF 时，任务的 PDF 交付仍未完成；无法预览或渲染时，明确说明版式尚未验证。不要声称不存在的文件已生成，也不要把中间材料标作最终可投递 PDF。
