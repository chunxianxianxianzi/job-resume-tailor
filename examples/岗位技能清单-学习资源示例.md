# 岗位技能清单 + 学习资源指南（示例）

> 本文件是「求职简历定制技能」中「岗位技能清单 + 学习链接」能力的产出样例。
> 覆盖两个代表岗位：① AI 训练师 / 数据标注；② AIGC 漫剧制作。
> 每项技能附学习资源示例（官方文档 / 社区教程 / 课程），供查漏补缺、自学提升。具体交付时应重新核对链接能否访问、页面是否对应技能，并区分官方与社区来源。

## 岗位一：AI 训练师 / 数据标注 / 多模态标注

### 1. 数据标注基础与工具
掌握数据标注的核心概念、标注类型与常用工具操作。

- **Label Studio 官方文档**（开源数据标注平台，图像/文本/音频/视频标注）：https://labelstud.io
- **Label Studio 快速入门教程**（官方视频）：https://labelstud.io/videos/getting-started-with-label-studio/
- **Label Studio 入门指南**（安装/建项目/标注流程）：http://labelstud.io.s3-website-us-east-1.amazonaws.com/guide/get_started.html

### 2. 大模型训练与对齐（SFT / RLHF / DPO）
理解大模型如何用标注数据训练，是 AI 训练师的核心知识。

- **PaddleNLP 大模型对齐教程**（SFT、RLHF、DPO 中文讲解 + 代码）：https://paddlenlp.readthedocs.io/zh/latest/llm/docs/alignment_tutorial.html
- **大模型数据标注完整技术指南**（SFT/RLHF 标注数据格式详解）：https://devpress.csdn.net/awstech/6a91b72a3bda720d4b354561.html
- **文生文 SFT 最佳实践**（百度千帆，数据准备/清洗/微调全流程）：https://cloud.baidu.com/doc/qianfan/s/Pmh4susgw

### 3. 指令优化与 Prompt 标注
理解 prompt-response 标注、对话标注与指令优化。

- **Anyscale 大模型 Post-training 指南**（SFT/RLHF 方法论）：https://docs.anyscale.com/llm/fine-tuning
- **RLHF & SFT 数据标注指南**（标注 rubric、金标准、一致性）：https://beyondhumanintelligence.com/ai-search-hub

### 4. 软素质（规则执行力、质检、质量意识）
- 金标准（Gold Standard）与标注者间一致性（IAA / Cohen's kappa）等质检方法论，可结合上述 Label Studio 文档中的 annotator performance 章节理解。

- 上述链接用于展示资源组织方式，不保证一直可访问。交付学习清单时记录实际核验结果；无法访问或内容不对应时重新寻找资源，不能把检索到标题等同于已检查页面。
