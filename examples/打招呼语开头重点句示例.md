# 打招呼语格式示例

本文件给 Agent 提供打招呼语的组织格式。Agent 应根据用户当前这份简历和已确认信息生成对应内容，再把生成后的完整段落交给用户复制使用。

**固定组织格式：您好 → 核心经验（在哪 / 多久 / 做什么）→ 关键技能 → 软素质 → 诚意结尾。**下面花括号中的内容均需从用户简历提取并替换，不是用户事实，也不能原样出现在最终打招呼语中。

## 生成规则

1. 读取当前目标岗位对应的用户简历，提取已确认的公司、职位、经历时间、职责、项目和技能；多岗位分别使用各自的简历。
2. 按上述格式组合成一段自然、简洁的话，不照抄示例中的占位内容，不补造经历。
3. 没有工作或实习经历时，使用简历中的项目或实践经历；没有明确经历时，可用已确认的专业背景与技能开头，不虚构公司或时长。
4. 关键技能一般挑最对口的 3~4 项，已确认的技能不足时按实际数量写。工具名称及「了解 / 熟悉 / 熟练 / 能独立完成」等表述应与用户简历及已确认信息一致。
5. 软素质从简历或已确认信息提取；没有依据时可省略。不得因为岗位需要某项素质就声称用户具备。
6. 到岗时间、可实习时长和工作安排仅在用户已确认时写入；未确认时直接用「期待与您进一步沟通」结尾，不默认加入「可尽快到岗」「可长期实习」。
7. 检查生成结果中的公司、经历时长、技能和承诺与用户简历一致，并删除未替换的占位符。

## 通用格式

> 您好，我有{简历中已确认的公司或项目、经历时长及工作内容}，{简历中已确认的关键技能与掌握程度}，{简历中有依据的软素质}，{用户已确认的到岗安排或实习时长，可省略}，期待与您进一步沟通。

不适用或没有依据的部分直接省略，调整连接词与标点，保留自然的完整段落。

## 岗位一：AI 训练师 / 数据标注

**突出对口经历：**

> 您好，我有{已确认的数据标注公司或项目及经历时长}经验，主要负责{简历中的标注任务}，{已确认的标注工具与掌握程度}，{简历中有依据的规则执行或质量意识描述}，{已确认的到岗安排，可省略}，期待与您进一步沟通。

**突出项目与质检：**

> 您好，我参与过{简历中的数据标注或质检项目}，主要完成{个人职责与已确认成果}，{已确认的相关技能与掌握程度}，{简历中有依据的软素质}，期待与您进一步沟通。

## 岗位二：AIGC 漫剧制作

**突出实际制作环节：**

> 您好，我有{简历中的漫剧或相关内容制作经历}，主要负责{实际参与的制作环节}，{已确认的生成或剪辑工具与掌握程度}，{简历中有依据的审美或协作能力描述}，{已确认的到岗安排，可省略}，期待与您进一步沟通。

**突出作品与问题解决：**

> 您好，我参与过{简历中的作品或项目}，负责{个人制作职责}，运用{已确认的工具或方法}完成{简历中的实际成果}，{简历中有依据的软素质}，期待与您进一步沟通。
